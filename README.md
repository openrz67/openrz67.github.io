# openrz67.github.io

Project site for [openrz67](https://github.com/openrz67), served by GitHub Pages from `main`.

Plain HTML and CSS in `index.html`; images in `img/`. No build step.

`img/case-pcb.jpg` is a Blender render of the local `openrz67-trigger` enclosure
(`case/openrz67_case.py`) and KiCad board (`pcb/kicad/openrz67.kicad_pcb`),
exported on 2026-09-15. The lid and light pipe are lifted 42 mm; the PCB is
lifted 16 mm. Battery, switch and wiring are omitted. Case colour is illustrative.

**Stale:** rendered from `main` at `ef389f2`, before the KCD11 rocker landed
(`5880bd7`, 2026-09-16). The lid still shows the old SS12F15 slide-switch slot and
its two M2 screw holes in the front wall, instead of the single snap-in opening.
Re-render from the current case script.
